## 参照するときの注意

⚠ **「ADR 0013 決定8」のような決定番号での参照は、本体に転記されているものだけを使う。**
決定7〜11 は長らく再設計計画 §16.8 の表にしか無く、参照先を開いても書いていない状態だった
（→ 課題#47。2026-09-05 に ADR 0013 へ転記して解消）。
**決定を増やしたら、まず ADR 本体へ書く。**
