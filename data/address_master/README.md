# 住所マスタの原典（位置参照情報）

`m_address_points` を作るための原典データ。**「その町に丁目が実在するか」を判定する
唯一の根拠**であり、これが無いと `normalize_address` は番地を丁目と誤認したままになる
（→ 課題#48・ADR 0020）。ハザード評価（→ 課題#46）の丁目代表点もこの表から引く。

| 項目 | 内容 |
|---|---|
| 出典 | 「位置参照情報ダウンロードサービス」（国土交通省） <https://nlftp.mlit.go.jp/isj/> |
| データ | 大字・町丁目レベル 令和7年版（版 `19.0b`） |
| 取得日 | 2026-09-05 |
| ライセンス | 政府標準利用規約（第2.0版）。**出典明示のみが義務**で複製・再配布・改変・商用利用が可 |
| 範囲 | 埼玉県・千葉県・東京都・神奈川県の4都県 21,473行 |

エリア帯（東京23区・近郊60分圏）が1都3県に収まるため4都県だけを置いている。
エリアを広げるときは `fetch_address_master.py` の `DEFAULT_PREFECTURES` に足して取り直す。

## 列

原典の10列をそのまま保つ（加工は文字コードの変換だけ）。

| 列 | 内容 |
|---|---|
| `都道府県コード` / `都道府県名` | JIS X 0401 |
| `市区町村コード` / `市区町村名` | **JIS5桁**。`m_cities.jis_code` と直接突き合わせられる。政令市は `さいたま市西区`、郡部は `北足立郡伊奈町` のように連結表記 |
| `大字町丁目コード` / `大字町丁目名` | 丁目は漢数字（`内幸町一丁目`）。大字は `大字` を含む表記が混じる |
| `緯度` / `経度` | 代表点（世界測地系） |
| `原典資料コード` | 0=自治体資料 / 1=街区レベル位置参照情報 など |
| `大字・字・丁目区分コード` | **1=大字 / 2=字 / 3=丁目**（実測 6,917 / 54 / 14,501件。ほかに 0 が1件） |

⚠ **区分コードが要。** 「丁目」の有無を町名の正規表現から推測せず、この列で確定できる。
実測で**区分3は必ず末尾が漢数字の丁目**、**区分3以外にアラビア数字を含む町名は0件**だった。

## 更新のしかた

```powershell
uv run python scripts/tools/fetch_address_master.py --fetch
uv run house-search sync-addresses
uv run house-search regroup
```

⚠ **`--fetch` の後は必ず `sync-addresses` → `regroup` まで行う。** マスタだけ新しくしても
`t_listings.address_normalized` は作り直されない。

⚠ **CSVは生成物なので手で編集しない。** cp932 の原典を UTF-8 へ変換して保存しているだけで、
それ以外の加工はしていない。

⚠ **ダウンロードページのCGIを辿る必要はない。** 実体は
`https://nlftp.mlit.go.jp/isj/dls/data/{版}/{都道府県コード}000-{版}.zip` に直に置かれている
（実測 2026-09-05）。版が上がったら `fetch_address_master.py` の `VERSION` を更新する。

## 既知の特記事項

- **正規化すると同じキーになる原典行が2組ある**（実測・4都県 21,473行 → 21,471行）。
  どちらも `大字` の有無だけの違いで正当な同一化。`sync-addresses` は集約したうえで
  内訳を出力する（黙って潰さない）。
  - 飯能市 `原町` と `大字原町`
  - 流山市 `鰭ケ崎` と `大字鰭ケ崎`
- **区分1（大字）なのに「丁目」を含む町名がある**（桶川市 `坂田西一丁目`、
  上尾市 `大字壱丁目` / `壱丁目西` ほか9件）。丁目行として扱わず町名として持つ
  （原典が大字と言っているものを丁目へ格上げしない）。掲載側が `坂田西1-2-3` と
  書いた場合は「町がマスタに無い」経路のフォールバックで `坂田西1丁目` になり結果は正しい
- **小字（`早野字下夕田`）はこの原典に無い。** 大字・町丁目までしか持たないので、
  小字つきの住所を引くときは「字」の手前で引き直す（`dedup/address.py` の `_town_candidates`）
