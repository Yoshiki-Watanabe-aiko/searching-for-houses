# 丁目の実在を住所マスタで確かめてから番地を切り詰める

**状態: 採用（2026-09-05・Phase 5I 前半）**
**関連: ADR 0012（名寄せの住所正規化）を**補強**（撤回ではない）／課題#48・#46／要件定義書 §8・§11**

ADR 0012 は「正規化住所は**丁目まで**で打ち切る」と決めた。サイトによって粒度が
「番地まで（HOME'S）／丁目まで（多数）／町名まで（SUUMO）」とばらつくためで、
この決定そのものは実測で裏づけられており**いまも正しい**。

問題はその実装にあった。**丁目表記が無い住所では「最初の数字塊を丁目とみなす」**
という規則を置いていた（`西早稲田3-1-1` → `西早稲田3丁目`）。都市部では妥当だが、
**丁目が存在しない町に番地が付くと、その番地がそのまま丁目になる。**

```
埼玉県深谷市中瀬1480-1  →  埼玉県深谷市中瀬1480丁目   ← 実在しない住所
```

---

## 何が起きていたか（実測 2026-09-05・active 20,037掲載）

| 現れ方 | 件数 |
|---|---:|
| 番地誤認（そもそも丁目が無い町） | 1,005 |
| 丁目はあるが番号が範囲外（番地を読んだ） | 69 |
| **合計** | **1,074（掲載の5.4%）** |

⚠ **この欠陥は例外にならず、件数も減らない。** 存在しない住所が `dedup_key` になるので、
同じ住戸を他サイトが `中瀬` や別番地で書けば一致せず、**名寄せが静かに失敗して
ユニーク率が高く見えるだけ**になる。サイトの採否をユニーク率で判断してきた
（→ 課題#37）ので、判断材料そのものが歪んでいたことになる。

⚠ **DBの中だけを見ていても永久に気づけない。** ハザード評価（→ 課題#46）の
着手前実測で位置参照情報という**外部の正典**と突き合わせて初めて分かった。
設備の辞書・駅マスタ・市区マスタと同じ構図である。

象徴的な例: 横浜市緑区長津田町の `ジョイフルＩＳＨＩＩ` は **18掲載が1グループへ統合**された。
APAMAN だけが番地（2436-4）を持つため `長津田町2436丁目` として分断されていた。

---

## 決定

### 決定1: 住所マスタ `m_address_points` を持ち、丁目の実在を確かめる

正典は国土交通省「位置参照情報」（大字・町丁目レベル 令和7年版）。

- **政府標準利用規約（第2.0版）＝ CC BY 4.0 互換**で、複製・再配布・改変・商用利用が可。
  出典明示のみが義務なので、**原典CSVを `data/address_master/` に Git 管理下で置ける**
  （総務省コード表 → ADR 0014 と同じ扱い。再配布不可でGit外へ逃がした駅マスタ →
  ADR 0016 とは事情が違う）
- 取得は `scripts/tools/fetch_address_master.py --fetch`。⚠ **ダウンロードページのCGIを
  辿る必要はなく**、実体は `data/{版}/{都道府県コード}000-{版}.zip` に直に置かれている
- ⚠ **原典の「大字・字・丁目区分コード」（1=大字 / 2=字 / 3=丁目）が決め手。**
  「その町に丁目が実在するか」を町名の正規表現から推測せず確定できる
  （実測で区分3は必ず末尾が漢数字の丁目・区分3以外にアラビア数字を含む町名は0件）

### 決定2: 判定は3分岐にし、**分からないときは従来どおり**にする

| 状況 | 判定 |
|---|---|
| その丁目が実在する | 従来どおり丁目として採る |
| 町はあるが丁目が無い／番号が範囲外 | **町名まで降格**（数字は番地） |
| **町がマスタに無い** | **従来どおり丁目とみなす**（安全側のフォールバック） |

⚠ **マスタに無いことを「丁目が無い」と読み替えない。** 収録漏れや新設の町を
町名まで降格させると、別の丁目の住戸を同一視する**偽陽性**を生む。
ADR 0012 決定5（欠損はセンチネルで埋めずキーを作らない）と同じ考え方で、
**判定材料が無いときは何もしない**。

### 決定3: 明示的な「丁目」表記はマスタに問い合わせず信じる

サイトが「丁目」と書いているものは推測ではない。⚠ **これは既知の限界を残す判断である。**
実測でエイブルが番地を丁目欄に入れている掲載が10件あり（`さいたま市西区宮前町1598丁目`）、
これらは修正後も残る（掲載全体の 0.05%）。覆す実装にすると、マスタが古いときに
**正しい丁目表記まで町名へ降格させる**ので、偽陽性のコストのほうが大きい。

### 決定4: 正規化は掲載側と原典側で**同じ関数**を共用する

`normalize_base`（NFKC・空白除去・ハイフン統一・大字/字の除去・ヶケ→が・漢数字丁目→アラビア）
を切り出し、`normalize_address`（掲載側）と `address_master`（原典側）の双方が通す。

⚠ **原典に別の正規化を当ててはいけない。** 突き合わせが0件になったとき
「マスタに無い」のか「正規化がずれている」のかを区別できなくなる。

### 決定5: 索引はDBから作り、純関数へ**引数で渡す**

`normalize_address(address, prefecture, index=AddressIndex)`。
`commute/matcher.py` の `StationIndex` と同じ形で、`dedup/address.py` はDBに触らないまま保つ。
⚠ **`index` を省略したときの挙動は従来と完全に同じ**にしてある（マスタ未同期の環境で
結果がぶれないため）。索引が空のときは `regroup` が止まり、`scan` は警告する。

### 決定6: 小字は「字」の手前で引き直す

位置参照情報が持つのは大字・町丁目までで、**小字（`早野字下夕田`）は無い**。
`_town_candidates` が「字」の手前も候補にする。

⚠ **「字」を `normalize_base` で無条件に落としてはいけない。** 町名の一部に「字」を含む
地名が実在する（小田原市 `十字四丁目`）。マスタに当たった候補だけを採れば壊さずに済む。

### 決定7: `DEDUP_KEY_VERSION` を `v1` → `v2` へ上げる

正規化住所が変わるので、新旧キーが混在して半端に一致する事故を防ぐ
（ADR 0012 が定めた手順どおり `regroup` で全再計算する）。

## 実測（2026-09-05・active 20,037掲載）

| 指標 | 適用前 | 適用後 |
|---|---:|---:|
| 丁目まで完全一致 | 18,581（92.7%） | **19,661（98.1%）** |
| 町名で解決 | 341（1.7%） | 341（1.7%） |
| **マスタ未一致** | **1,115（5.6%）** | **35（0.2%）** |
| `[0-9]{4}丁目`（誤認の痕跡） | 394 | **2** |
| 名寄せグループ | 9,652 | **9,160**（492減） |
| クロスサイト一致グループ | 3,231 | **3,341（+110）** |
| 通知履歴 `t_notifications` | 1,086 | **1,086（不変）** |

⚠ **解決率は掲載全体を分母に測る**（→ 課題#41 の「分母を取り違えると健全に見える」）。

**偽陽性の検証**（ADR 0012 と同じ手法。統合されるグループ内の建物名の食い違いを目視）:
統合される481グループのうち、建物名が一致93 / 片方が匿名掲載176 / 食い違い212。
食い違いから15件を目視して14件は表記ゆれで実質同一（`サニーサイド`／`サニー・サイド`、
`ジョイフルＩＳＨＩＩ`／`ジョイフルISHII`）で、真の偽陽性は1件だった。

**残る未一致35件に番地誤認は1件も含まれていない**（原因はすべて別）。

| 残る原因 | 件数 |
|---|---:|
| エイブルが番地を「丁目」と表記（→ 決定3） | 10 |
| UR・ハウスコムの住所が市区までしか無い | 8 |
| ホームメイトの住所欄の汚染（課題#44 で修正済み・再取得待ち） | 6 |
| `resolve_city` が誤った都道府県を前置（`長野県埼玉県加須市…`） | 5 |
| その他（サイト側の表記ゆれ） | 6 |

## 却下した案

| 案 | 却下の理由 |
|---|---|
| 「丁目」の実在を正規表現で推測する（3桁以上は番地とみなす等） | 実在する `975丁目` が無いことを保証できない。閾値は結局あてずっぽうで、**外したときに黙って壊れる**のは現状と変わらない |
| ジオコーディングAPIで座標を引いてから判定する | レート制限と障害に実行時が依存する。`rescore` がネットワーク不要という性質（→ 要件定義書 §6.1）を壊す |
| マスタに無い町も「丁目が無い」とみなす | 収録漏れ・新設の町で**偽陽性**（別丁目の同一視）を生む。名寄せの誤爆はランキングから住戸を1件消すので、偽陰性より高くつく（→ ADR 0012） |
| 正規化で「字」を無条件に落とす | 小田原市 `十字四丁目` のように町名の一部が壊れる |
| 原典を Git 管理外にする（駅マスタ方式） | ライセンスが再配布を認めているので不要。**Git に置けば「いつ時点の版で作ったマスタか」を後から言える** |
