## #1 ABLE・SMOCCA が市区町村未指定だと0件になる

- 状態: 未解決
- 内容: ABLE・SMOCCAは市区町村（`conditions.area.cities`）の指定が必須で、都道府県のみの指定では検索結果が0件になる。現状の `configs/chintai_alone.yaml` は `cities` を指定していないため、この2サイトが機能していない。
- 対応履歴:
  - 2026-07-10: `docs/詳細設計書/01_検索条件マッピング設計.md`の調査で判明。対応策は `cities` テーブルの `canonical_name` を使って `cities` を指定すること（`docs/詳細設計書/01_検索条件マッピング設計.md` 参照）。

## #6 DBテーブル命名がm_/t_接頭辞規約に非準拠

- 状態: 未解決
- 内容: `~/.claude/DB_CONVENTIONS.md`（`~/.claude/CLAUDE.md`データベース設計方針）は「マスタテーブルは接頭辞に`m_`、トランザクションテーブルは接頭辞に`t_`」と規定しているが、本プロジェクトの実テーブルは非準拠。
  - マスタ相当: `property_type_master`, `site_master`, `condition_category_master`, `condition_master`, `condition_property_type_map`, `site_condition_map`, `cities`, `city_site_mappings`
  - トランザクション相当: `properties`, `notifications`, `scrape_logs`

- 対応履歴:
  - 2026-07-10: project-scaffold適用時の規約突き合わせで発見。リネームは`db/*.sql`・`internal/db/*_repo.go`・`docs/requirements.md`の全ER記述に影響するマイグレーションを伴うため、方針決定と実施はユーザー判断に委ねる（自動修正はしていない）。
