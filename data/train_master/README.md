# 駅マスタの原典（Git管理外）

通勤時間による絞り込み（Phase 5C）で使う駅・路線データ。

⚠ **このディレクトリのCSVは再配布不可のため Git 管理外にしてある。**
このREADMEだけが追跡対象（`.gitignore` の否定パターン）。

| 項目 | 内容 |
|---|---|
| 出典 | 駅データ.jp 無料版 <https://ekidata.jp/> |
| 取得日 | 2026-09-03 |
| ライセンス | 無料会員登録が必要。**再配布不可**。利用時はクレジット表記 |

## ファイル

| ファイル | 内容 |
|---|---|
| `station********free.csv` | 駅（駅名・路線・緯度経度・**駅グループコード**） |
| `line********free.csv` | 路線 |
| `join********.csv` | 駅の接続関係 |
| `company********.csv` | 事業者 |

**駅グループコードを持つことがこのデータを選んだ決め手**。同名で別の駅
（日本橋＝東京/大阪、府中＝東京/広島）と乗換駅の統合が済んでおり、
掲載の `station_info` から駅を同定する一番難しいところを自前で作らずに済む。

## 再取得のしかた

1. <https://ekidata.jp/> で無料会員登録してログイン
2. 「データダウンロード」から上記4種のCSVを取得
3. このディレクトリへ置く（ファイル名の日付部分は取得時期で変わる）

## 分かっている限界

⚠ **新幹線の駅が1件も入っていない。** `line` には東海道・上越・北陸などの路線が
`e_status=0`（営業中）で存在するのに、`station` 側に属する駅が0件である。
そのため本庄早稲田のような**新幹線専用駅は同定できない**（実測で48掲載・
いずれもエリア帯の外なので実害は無い）。東京・上野・大宮・新横浜などは
在来線側で収録されているので影響しない。

⚠ **`join*.csv` は通勤時間の算出に使う**（→ ADR 0016）。`resolve-commutes` と
`scan` が実行時に読むので、このディレクトリが無いと通勤時間を更新できない。
`scan` はその場合もエラーとして記録するだけで処理は止めない。
