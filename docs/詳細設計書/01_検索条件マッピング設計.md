# 検索条件マッピング機能設計

最終更新: 2026-07-10（`docs/scraper-capabilities.md` を本書に統合し詳細設計書として切り出し）

## 概要

YAML検索パターン（`configs/*.yaml` の `conditions`）を各不動産サイトのURLパラメータ・フォーム値にどうマッピングするかを定義する。サイトごとに対応できる条件の範囲が大きく異なるため、実装済み/未実装の状態をこの文書で管理する。

サイト別の生データ（各サイトの検索フォームで実際に選べる選択肢の全量）は [`資料_サイト別検索条件一覧.md`](./資料_サイト別検索条件一覧.md) を参照。本書はその資料をもとにした「現状のスクレイパー実装が何に対応しているか」の設計・実装状況ドキュメント。

対応サイト一覧・条件コード一覧の正は `docs/requirements.md` 2章・5章。

## 3. 実装メモ（スクレイパー別）

| サイト | 方式 | 特記事項 |
|--------|------|----------|
| SUUMO | HTTP + goquery | `ta`（JIS2桁）+ `ar`（地域コード）で都道府県検索。`tc=`（7桁コード）で設備条件10種、`ct=`で家賃上限、`co=3/4`で礼金・敷金なし |
| HOMES | HTTP + goquery | 複数都道府県ループ未実装（第1都道府県のみ使用） |
| ATHOME | HTTP + goquery | `KODAWARI[]=`で設備条件8種。**AND条件**のため重ねすぎ注意（→ [課題#3](../課題管理表.md)） |
| GOO | HTTP + goquery | `g=pref`検索は他府県も混入するため後段でprefectureフィルタ済。JS動的ロードのため設備条件は絞り込み不可 |
| ABLE | HTTP + goquery | 市区JIS5桁必須。都道府県のみでは0件 |
| MINIMINI | HTTP + goquery | Shift-JISエンコーディング対応済。フィルタなし |
| EHEYA | Playwright (go-rod) | フィルタなし。Chrome要インストール |
| NIFTY | Playwright (go-rod) | `{param}=1`形式で50以上の条件対応。`ex16=1`礼金なし、`ex15=1`敷金なし |
| APAMAN | Playwright (go-rod) | 市区URLは`/kensaku/list/?search_type=area&target[0]={code}`形式。フリーワード検索のみ |
| SMOCCA | Playwright (go-rod) | `cond[reikin]=true`礼金なし、`cond[shikikin]=true`敷金なし。市区スラグ必須 |

条件を追加実装する際は、上記の「実装済み」列にサイトを追加し、対応するスクレイパー（`internal/scraper/{site}/scraper.go`）にパラメータ組み立て処理を追加する。未実装のまま残っている拡張候補は [`docs/課題管理表.md`](../課題管理表.md) の #2・#4 を参照。
