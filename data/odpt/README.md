通勤時間を実ダイヤから算出する（Phase 5D）ために使う鉄道時刻表データ。

⚠ **このディレクトリの取得データは Git 管理外にしてある。**
このREADMEだけが追跡対象（`.gitignore` の否定パターン）。
[公共交通オープンデータ基本ライセンス](https://ckan.odpt.org/)は
**第三者への生データ再配布に制約がある**ため（利用そのものは商用・非商用を問わず可）。

## なぜ駅データ.jp だけでは足りないのか

[`../train_master/README.md`](../train_master/README.md) の駅データ.jp 無料版には
**時刻表も駅間所要時間も入っていない**（駅・路線・接続・事業者の4ファイルのみ）。
そのため Phase 5C の通勤時間は `8.7 + 1.14 × 距離km + 5.6 × 乗換回数`（分）という
回帰式で、**平均誤差5.6分・最大16.0分**にとどまる（→ ADR 0016）。
優等列車・待ち時間・直通運転を式で表現できないことが原因。

**両方を併用する。** 駅の同定（掲載の駅表記 → 駅グループ）は駅データ.jp の
`station_g_cd` が正典のまま変えず、ODPT は**辺の重み（駅間の実所要時間）専用の追加素材**として使う。

## 実測したカバー範囲（2026-09-03 時点）

CKAN のデータセット検索で数えた実数。**全事業者は揃わない**ので、
時刻表のある区間と無い区間のハイブリッドになる。

| 提供データ | 事業者 |
|---|---|
| **列車時刻表**（列車ごとの全停車駅の時刻＝駅間所要時間が直接取れる）10社 | JR東日本・東京メトロ・都営・東武・京王・相鉄・つくばEX・りんかい線・横浜市営・多摩都市モノレール |
| **駅時刻表のみ**（発車時刻。駅間所要時間は隣接駅の突き合わせで推定）5社 | 東急・小田急・京急・西武・ゆりかもめ |
| **未参加** | 京成・北総・東葉高速・埼玉高速・東京モノレール など |

## ディレクトリ構成

| パス | 内容 |
|---|---|
| `raw/{事業者}/railway.json` | 路線 `odpt:Railway` |
| `raw/{事業者}/station.json` | 駅 `odpt:Station` |
| `raw/{事業者}/train_timetable.json` | 列車時刻表 `odpt:TrainTimetable` |
| `raw/{事業者}/station_timetable.json` | 駅時刻表 `odpt:StationTimetable` |

## 再取得のしかた

```powershell
uv run python scripts/tools/odpt_spike.py --operator Toei
```

⚠ **`scripts/tools/odpt_spike.py` は調査用の使い捨てスクリプト**で、
本番の取得コマンドは Phase 5D 第1段で `fetch-odpt` として実装する。

## 分かっている限界・確認中の事項

- ⚠ **`odpt:arrivalTime` は仕様上の任意項目**。到着時刻の無い列車がどれだけあるかは
  実データで確認する（欠落時は「次駅の出発時刻 − 区間代表秒」で補う想定）
- ⚠ **APIホストが2つある可能性**。旧「東京公共交通オープンデータチャレンジ」の
  `api-tokyochallenge.odpt.org` から `api.odpt.org` へ移行した経緯があり、
  事業者によって片方にしか無いことがある（スパイクスクリプトが両方試す）
- ⚠ **恒常提供か期間限定かを登録時に確認すること**。ODPT には
  「公共交通オープンデータチャレンジ」参加者向けの期間限定データが混ざる
