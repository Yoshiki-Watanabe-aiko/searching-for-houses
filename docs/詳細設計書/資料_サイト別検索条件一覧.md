# 不動産サイト検索条件一覧（全物件種別）

> 本ドキュメントは各サイトの検索フォームで選択可能な項目を網羅した**生データ資料**。
>
> **v2 での位置づけ（2026-09-01）**: v2 ではサイトの検索フォームへ渡すのを
> **エリア・物件種別・価格上限の3つだけ**に限定し、設備条件・間取り・面積・築年数・
> 徒歩分数の判定はローカルで行う（→ [ADR 0003](../adr/0003-local-filtering.md)）。
> そのため本資料の「こだわり条件」の各節は**実装への入力ではなくなった**が、
> ①エリア指定方式とURL構築、②売買4種別の一覧URL、③各サイトが持つ設備語彙
> （＝設備抽出辞書の初期候補）として引き続き有効なため保持する。

**作成日**: 2026-06-24  
**対象**: 賃貸・新築マンション・中古マンション・新築一戸建て・中古一戸建て（全5種別）  
**取得方法**: Playwright ブラウザ経由（全5サイト・全5種別取得済み）  
**最終更新**: 2026-06-24（売買4種別: SUUMO・HOME'S・athome・goo・ニフティ完全取得）
