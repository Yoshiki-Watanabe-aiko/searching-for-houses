## #1 ABLE・SMOCCA が市区町村未指定だと0件になる

- 状態: **対応中**（設計上の解消方針は確定。実装は Phase 2）
- 内容: ABLE・SMOCCAは市区町村の指定が必須で、都道府県のみの指定では検索結果が0件になる。
- 対応履歴:
  - 2026-07-10: `docs/詳細設計書/01_検索条件マッピング設計.md`の調査で判明。
  - 2026-09-01: v2 の方針を確定。YAML の `search.cities` が空のとき、この2サイトについては
    `m_cities` から都道府県内の全市区へ自動展開する（`m_city_site_values` に行があるものが対象）。
    Phase 2（HTTP展開）で実装する。

## #2 スクレイパー未実装の条件追加（HOMES/ATHOME/GOO/APAMAN/ABLE/SMOCCA）

- 状態: **クローズ**（対応不要）
- 内容: 各サイトの検索フォームへ礼金なし・敷金なし・面積下限などのパラメータを追加する残作業。
- 対応履歴:
  - 2026-07-10: `docs/scraper-capabilities.md`（統合前の旧ドキュメント）から引き継ぎ記録。
  - 2026-09-01: v2 でサイト側フィルタをエリア・種別・価格上限の3つに限定したため対応不要化。
    これらの条件はすべてローカルの MUST/WANT 判定で扱う（→ ADR 0003）。

## #3 ATHOME設備条件のAND検索チューニング

- 状態: **クローズ**（対応不要）
- 内容: ATHOMEの設備条件（`KODAWARI[]`）はAND条件のため、多数同時指定すると該当件数が極端に少なくなる。
- 対応履歴:
  - 2026-07-10: 発見・記録。
  - 2026-09-01: v2 で設備条件をサイト側へ渡さなくなったため対応不要化（→ ADR 0003）。
    WANT の設備は「無くても減点で残す」ため、そもそもAND絞り込みと相容れない。
